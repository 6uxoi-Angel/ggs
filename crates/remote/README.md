# Integra Remote (агент)

Фоновый агент родительского контроля. Встроен в Integra 3 и доступен
также как отдельный бинарник `integra-agent.exe` (этот крейт).

## Что делает

- Соединяется с сервером управления (см. `C:\Users\neuzu\Desktop\remote-server\`)
  **исходящим** подключением — проброс портов и белый IP на клиенте не нужны.
- Раз в ~20 секунд шлёт heartbeat; сервер видит онлайн/офлайн.
- Выполняет команды сервера:
  - `block_app` / `unblock_app` — правило исходящего файрвола Windows
    для конкретного exe (+ принудительное завершение процесса). Приложение
    ведёт себя как «интернет пропал», а не «заблокировано родителями».
  - `block_site` / `unblock_site` — запись в `hosts` (`0.0.0.0` и `::1`)
    + сброс DNS-кэша. Браузер показывает обычную ошибку «не удаётся найти сайт».
- Ничего не блокирует само по себе — только то, что приказал сервер.

## Сборка агента (Windows)

```bash
cd C:\Users\neuzu\Desktop\ggs
# обычный вариант (сервер по умолчанию 135.106.174.221:9443,
# токен `change-me` — замените!):
cargo build --release -p integra-remote
# → target\release\integra-agent.exe

# с токеном и ссылкой на GitHub-список серверов:
AGENT_TOKEN=мой_секретный_токен \
AGENT_FALLBACK_SERVERS=135.106.174.221:9443 \
AGENT_SERVERS_URL=https://raw.githubusercontent.com/<логин>/<репо>/main/servers.json \
cargo build --release -p integra-remote
```

Переменные `AGENT_*` **зашиваются в бинарник на этапе сборки** — ребёнок
не сможет их поменять без пересборки.

## Установка на машину ребёнка

1. Скопировать `integra-agent.exe` в `C:\Program Files\NetProtect\` (папку
   можно назвать иначе — имя файла/папки нейтральное).
2. Запустить один раз от администратора с ключом `--install` — создаст
   скрытую задачу `IntegraRemote` (каждые 5 минут, под SYSTEM, даже без
   входа в систему). Удаление: `--uninstall`.
3. Проверить на сервере: `list` → клиент ONLINE.

Альтернатива: открыть Integra → Настройки → «Удалённый контроль», ввести
токен и серверы, включить агент и «Автозапуск с Windows (скрыто)» — тогда
в фоне работает сам exe Integra (`--remote-run`) через ту же задачу.

## Что лежит где

| Путь | Содержимое |
|---|---|
| `C:\ProgramData\NetProtect\state.json` | id машины + активные блокировки (применяются заново при каждом старте) |
| `C:\ProgramData\NetProtect\` (логи в debug-режиме) | служебное |
| hosts-файл | строки с меткой `# netguard-block` (удаляются при `unblock_site`) |

## Ограничения (честно)

- Процесс виден в «Диспетчере задач»; полностью скрыть нельзя.
- Трафик не шифруется (TLS — будущая итерация); токен защищает от чужих.
- DNS-блокировка не работает, если браузер использует DoH (Encrypted DNS).
- Антивирусы могут ругаться на правку hosts/файрвола — добавьте исключение.
