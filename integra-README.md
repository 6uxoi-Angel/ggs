# Integra 3

GUI-оболочка для **Zapret** на Rust + Tauri 2. Управляет обходом блокировок: профили, стратегии, списки обхода, мониторинг подключений приложений, диагностика и автоматический подбор лучшей стратегии.

> Integra — независимый проект и **не является частью Zapret**. Используйте в соответствии с законодательством вашей страны.

---

## Возможности

### 🗂 Профили
- Несколько **независимых установок** zapret одновременно (мультипрофили) — у каждого своя папка, стратегия и списки
- Активный профиль, включение/отключение, автозапуск при старте Integra
- Запуск/остановка в один клик; для работы winws (WinDivert) запрашиваются права администратора (UAC)

### 🎯 Стратегии
- Автообнаружение стратегий (`general*.bat`) в папке профиля
- Быстрое переключение стратегии без перезапуска приложения
- Установка/удаление **службы Windows** для фонового режима

### 📡 Приложения (мониторинг сети)
- Трекинг «куда ходит процесс»: снапшоты таблиц TCP/UDP-соединений (iphlpapi — тот же источник, что у TCPView)
- **Карточки активных приложений**: кто сейчас забирает трафик, число соединений, ваши IP, основные адреса
- Фильтр по имени процесса (подстрока) или явным PID
- **Авто-подхват** приложений, запущенных после старта сессии («нажал запись → запустил игру»)
- Обратный DNS (имена хостов), метки известных портов, счётчики повторов, first/last seen
- Экспорт сессии в CSV

### 📋 Списки обхода
- Два основных списка: `list-general` (bypass) и `list-exclude`, плюс специфичные наборы
- **Общие списки**: профиль может использовать единый набор списков (для всех профилей) или свои индивидуальные — переключается одним флажком
- Умная нормализация: URL → домен (даже с путём и запросом), поддержка CIDR, валидация ввода, дедупликация
- Естественная сортировка (natural sort), мгновенные счётчики записей
- Правка из приложения и через браузерное расширение

### 🩺 Диагностика
- Проверка сайтов: DNS → TCP → **реальный TLS-handshake** (rustls + webpki-roots) → HTTPS HEAD
- Замер латентности каждого этапа, системная информация
- Настраиваемый список сайтов для проверки

### 🏆 Бенчмарк стратегий
- Автоматический перебор всех `general*.bat` профиля: стоп → старт → прогрев → проверки → оценка
- Скоринг по диагностическим сайтам, наглядный рейтинг с лучшей стратегией ★
- Полное **восстановление исходного состояния** после прогона, отмена в любой момент

### 🌉 Мост + браузерное расширение
- Локальный HTTP-мост (token-авторизация, **пейринг по 6-значному коду** с таймером)
- Расширение (Manifest V3, `browser-extension/`): статус zapret, добавление домена в bypass/exclude прямо из браузера, захват всех URL открытой вкладки
- Безопасное API: домены проходят ту же валидацию, что и в UI

### 🔄 Обслуживание zapret
- Проверка новых релизов `Flowseal/zapret-discord-youtube` и авто-скачивание
- Безопасная распаковка (защита от zip-slip, symlink-атак, лимиты размеров)
- Перенос ваших списков в новую установку, **backup/rollback**, метаданные `.integra-zapret.json`

### 🛠 Режим разработчика
- 10 быстрых кликов по вкладке «Настройки» включают скрытый режим
- Кнопка **«Открыть dev логи»**: отдельное окно консоли с полным потоком событий (уровень, модуль кода, время) в реальном времени — для анализа ошибок
- Файл `dev.log` пишется всегда, rotates при 8 МБ; дополнительно открывается DevTools WebView

### 🎨 Интерфейс
- Три темы: `dark_accent`, `dark`, `light` (glassmorphism, плавные анимации, скелетоны, тосты)
- **Кастомизация темы**: цвет каждого элемента (акцент, фон, панели, вкладки, текст, границы, статусы), фоновые изображения для панели вкладок и содержимого, **сохранение наборов как пресеты**
- **Панель вкладок**: расположение сверху/снизу/слева/справа, стили обычный/компактный/иконки, анимированный индикатор активной вкладки
- **Справка на каждой вкладке** — кнопка «?» с подробным описанием всех кнопок и процессов
- Локализация RU / EN
- Трей с меню, сворачивание в трей вместо закрытия, single-instance, восстановление геометрии окна
- Автоматическая миграция настроек из Integra 2.x при первом запуске

## Системные требования

| Компонент | Требование |
|---|---|
| ОС | Windows 10 / 11 (x64) |
| Rust | toolchain `stable-x86_64-pc-windows-msvc` |
| Сборка C++ | Visual Studio Build Tools (Desktop development with C++) |
| WebView2 | в Win11 предустановлен; инсталлятор ставит сам (embed bootstrapper) |
| Zapret | скачайте через приложение или укажите путь к `zapret-discord-youtube` |

## Сборка и запуск

```powershell
# зависимости не нужны (UI — статические файлы в crates/app/ui)

# запуск в dev-режиме
cargo run -p integra-app

# или через CLI (удобно для разработки)
cargo install tauri-cli --version "^2"
cargo tauri dev

# релизная сборка: exe + NSIS-инсталлятор
cargo tauri build
# → target/release/bundle/nsis/Integra_3.0.0_x64-setup.exe
```

## Первый запуск

1. Приложение создаст конфиг в `%APPDATA%\Integra`
2. Скачайте zapret в разделе обслуживания (само подтянет последний релиз Flowseal) или создайте профиль, указав путь к существующей папке `zapret-discord-youtube`
3. Выберите стратегию и запускайте профиль (подтвердите UAC)
4. Для браузерного расширения: страница расширений → режим разработчика → «Загрузить распакованное» → папка `browser-extension` → введите код привязки из Integra
5. Режим разработчика: 10 быстрых кликов по вкладке «Настройки» → в настройках появится кнопка dev-логов

## Структура проекта

```
crates/
├── core/    профили, конфиг, списки, i18n, лог-буфер, миграция 2.x
├── zapret/  менеджер запуска winws, службы, генерация runtime-BAT,
│            обслуживание (скачивание/обновление zapret)
├── netmon/  трекинг подключений процессов (iphlpapi / /proc)
├── diag/    DNS/TCP/TLS/HTTP-проверки, латентность
├── bridge/  HTTP-мост для браузерного расширения (token + пейринг)
└── app/     Tauri-приложение: ~58 команд, события, трей, бенчмарк + UI
crates/app/ui/       весь интерфейс (HTML/CSS/JS без сборки)
browser-extension/   расширение Chrome/Edge (Manifest V3)
```

Библиотечные крейты покрыты юнит-тестами (58 шт.): `cargo test --workspace --exclude integra-app`.
