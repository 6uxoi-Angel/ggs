# Integra — браузерное расширение (Chrome / Edge, Manifest V3)

Расширение подключается к локальному HTTP-мосту приложения Integra
(`127.0.0.1`, порт по умолчанию `8765`, API v2 — см. `crates/bridge/src/lib.rs`)
и позволяет управлять списками zapret прямо из браузера:

- **В обход** — добавить сайт в список обхода (bypass);
- **В исключения** — добавить сайт в список исключений (exclude);
- **Убрать** — удалить домен из всех списков профиля;
- **Захватить все ссылки вкладки** — собрать все `a[href]` открытой страницы
  (+ hostname самой страницы) и массово добавить домены (`POST /api/domains`,
  до 2000 штук);
- выбор профиля Integra, просмотр состояния zapret, стратегии и счётчиков списков.

Мост слушает только `127.0.0.1`, принимает запросы исключительно с Origin
`chrome-extension://…`, а все обращения к `/api/*` требуют Bearer-токен,
который расширение получает при привязке. Токен хранится локально
(`chrome.storage.local`) и никуда, кроме моста Integra, не отправляется.

---

## Установка (режим разработчика)

1. Открой страницу расширений:
   - **Chrome:** `chrome://extensions`
   - **Edge:** `edge://extensions`
2. Включи переключатель **«Режим разработчика»** (Developer mode).
3. Нажми **«Загрузить распакованное расширение»** (Load unpacked) и выбери
   папку `browser-extension/` (ту, где лежит `manifest.json`).
4. Появится иконка Integra — закрепи её на панели (значок «pins»/«пазл»),
   чтобы попап открывался в один клик.

Обновление файлов расширения: после правок нажми «↻» (Update / Перезагрузить)
на карточке расширения.

## Привязка к Integra

1. Запусти приложение Integra.
2. Перейди на вкладку **«Расширение»** — там показан **код привязки**
   (6 цифр, действует 15 минут; кнопка рядом генерирует новый код).
3. Кликни по иконке Integra в браузере и введи код → **«Подключить»**.
4. Расширение получит токен и сохранит его. Готово — можно добавлять сайты.

### Если подключиться не удаётся

- **«Integra не запущена»** — приложение не запущено, либо мост не запущен
  (вкладка «Расширение» → включить мост / запустить прослушивание).
- **Другой порт** — если порт в Integra изменён с `8765`, расширение само
  покажет поле ручного ввода порта; укажи порт из приложения и нажми
  «Проверить».
- **«Неверный код привязки»** — код просрочен (15 минут) или был
  сгенерирован заново; возьми актуальный код из приложения.
- **«Привязка недействительна»** — токен сброшен (например, мост
  перегенерировал токен в приложении). Нажми «Привязать заново» в попапе.

## Как пользоваться

- Открой сайт, который нужно пустить в обход, и нажми **«В обход»** — в поле
  «Цель» подставится hostname сайта. Можно и вписать домен вручную
  (`example.com`).
- **«Захватить все ссылки вкладки»** — соберёт все домены со ссылок страницы.
  Переключатель над кнопкой выбирает режим массового добавления
  (в обход / в исключения).
- Изменения списков требуют **перезапуска zapret** — расширение напомнит об
  этом (жёлтая плашка «Изменения сохранены…»).
- Язык интерфейса выбирается автоматически: английский для браузеров с
  английской локалью, иначе русский.

## Файлы

| Файл | Назначение |
|---|---|
| `manifest.json` | MV3-манифест (permissions, service worker, иконки) |
| `api.js` | общий модуль: fetch-клиент моста, нормализация доменов, storage |
| `background.js` | service worker: захват ссылок вкладки, bulk-добавление |
| `popup.html/.css/.js` | попап: привязка, статус, действия, RU/EN-локализация |
| `_locales/ru|en/messages.json` | локализация имени/описания расширения |
| `icons/` | PNG-иконки 16/32/48/128 |

## Приватность и безопасность

- Мост доступен только с `127.0.0.1`; Origin сторонних сайтов мост отклоняет.
- Токен передаётся только в заголовке `Authorization` локальному мосту.
- Захват ссылок выполняется только по явному нажатию кнопки и только на
  активной вкладке (разрешение `activeTab`).
