# Integra 3.0 — что нового по сравнению с версией 2.x

Предыдущая версия Integra (`Integra---zapret-gui`) была написана на **Python** с классическим десктоп-GUI. Версия 3.0 — это **полное переписывание на Rust** с новым интерфейсом и целым рядом функций, которых раньше не было. Ниже — детальное сравнение.

---

## Кратко: главное

| | Integra 2.x (Python) | Integra 3.0 (Rust) |
|---|---|---|
| Язык / стек | Python | Rust 2021, workspace из 6 крейтов |
| Интерфейс | нативный GUI | Tauri 2 + WebView2, web-UI с glassmorphism |
| Профили | одна установка | **мультипрофили** |
| Мониторинг приложений | — | **netmon: трекинг подключений процессов** |
| Бенчмарк стратегий | — | **автоперебор со скорингом** |
| Браузерное расширение | — | **Manifest V3 + мост v2 с пейрингом** |
| Обновление zapret | вручную | **авто-скачивание релизов Flowseal + rollback** |
| Диагностика | базовая | **реальный TLS-handshake (rustls)** |
| Тесты | — | **52 юнит-теста** |
| Миграция настроек | — | **автоподхват конфига 2.x** |

---

## Подробно

### 1. Новый стек и архитектура
- Монолит на Python → **Rust workspace**: `core` (профили/конфиг/списки/i18n), `zapret` (запуск winws, службы, обслуживание), `netmon`, `diag`, `bridge`, `app` (Tauri). Библиотечные крейты платформонезависимы и покрыты тестами, app-слой — тонкая обвязка над Tauri (48 типизированных команд вместо ad-hoc вызовов).
- GUI на web-технологиях, но без Node/npm — статические файлы, ничего собирать не надо.

### 2. Мультипрофили 🆕
- Раньше: одна установка zapret на систему.
- Теперь: **несколько независимых профилей** — у каждого своя папка zapret, своя стратегия и свои списки. Переключение одним кликом, у каждого профиля свой автозапуск.

### 3. Трекинг приложений (netmon) 🆕
- Целиком новый модуль: «куда ходит это приложение?»
- Снапшоты системных таблиц соединений (iphlpapi), фильтр по имени процесса или PID, **авто-подхват процессов, запущенных после старта сессии**, reverse-DNS имена хостов, метки известных портов, история first/last seen, экспорт в CSV.
- Практический сценарий: включили запись → увидели, во что играет игра → добавили хост в bypass.

### 4. Бенчмарк стратегий 🆕
- Автоматически перебирает все `general*.bat` профиля: для каждой стратегии — стоп → старт → прогрев → серия проверок диагностических сайтов → оценка.
- Рейтинг с лучшей стратегией ★, отмена в любой момент, **гарантированное восстановление исходного состояния** (стратегия/служба, которые были до прогона).

### 5. Браузерное расширение и мост v2 🆕
- Расширение (Chrome/Edge, Manifest V3): статус zapret, добавление домена в bypass/exclude одним кликом, **захват всех URL открытой вкладки** и отправка в Integra.
- Мост переработан: token-авторизация + пейринг по 6-значному коду с таймером; все домены проходят ту же валидацию, что и в UI.

### 6. Обслуживание zapret 🆕
- Проверка выхода новых релизов `Flowseal/zapret-discord-youtube`, скачивание и установка прямо из приложения.
- Безопасная распаковка архива (защита от zip-slip, symlink-атак, лимиты размеров), **перенос ваших списков** в новую версию, backup/rollback, метаданные установленной версии.
- В 2.x всё это делалось вручную.

### 7. Диагностика
- Было: базовые проверки доступности.
- Стало: цепочка DNS → TCP → **настоящий TLS-handshake** (rustls + webpki-roots, без системных утилит) → HTTPS HEAD, латентности каждого этапа, скоринг стратегий для бенчмарка, настраиваемые сайты.

### 8. Списки обхода
- Переработанный менеджер списков: нормализация URL → домен, поддержка CIDR, строгая валидация, дедупликация, natural sort (server2 < server10), мгновенные счётчики.
- Исправлены фундаментальные баги обработки списков (в т.ч. взаимная блокировка при записи, из-за которой изменения могли не сохраняться).

### 9. Надёжность запуска
- Генерация скрытого runtime-BAT на лету, отслеживание реального PID `winws.exe` (Toolhelp32), корректное завершение деревьев процессов, `CREATE_NO_WINDOW` без мелькающих окон.
- Single-instance, close-to-tray, восстановление геометрии окна, отложенный автостарт профилей.

### 10. Интерфейс
- Три темы (`dark_accent` / `dark` / `light`), glassmorphism, spring-анимации, скелетоны загрузки, тосты, модалки.
- Локализация **RU / EN** с переключением на лету.
- Логи: кольцевой буфер + живой стриминг в UI + экспорт.

### 11. Совместимость
- При первом запуске Integra 3 **автоматически мигрирует** конфигурацию из 2.x (`%APPDATA%\Integra`), включая профили и настройки.
- Требование к системе: Windows 10/11 + WebView2 (в Win11 уже есть; NSIS-инсталлятор ставит его автоматически).

## Сборка

В 2.x запускался интерпретатором Python. В 3.0 — компилируется:

```powershell
cargo run -p integra-app      # dev-запуск
cargo tauri build             # релиз: exe + NSIS-инсталлятор
```
